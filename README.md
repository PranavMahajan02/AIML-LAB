# AIML Lab Experiments

A collection of Python implementations developed as part of my **Artificial Intelligence and Machine Learning (AIML) Laboratory coursework**.

This repository brings together 12 experiments covering fundamental AI algorithms, Python libraries, data preprocessing, machine learning models, and clustering techniques. Each experiment focuses on understanding the underlying concepts and implementing them through practical Python programs.

The goal is to build a strong foundation in AI and ML by exploring how different algorithms work and how they can be applied to real-world problems.

## 📚 Experiments Covered

| No. | Experiment | Description |
|:---:|---|---|
| 01 | Breadth-First Search (BFS) | Explores graph traversal using a queue-based approach. |
| 02 | A* Search Algorithm | Implements heuristic-based pathfinding using path cost and estimated distance. |
| 03 | Tic-Tac-Toe | Implements a simple interactive Tic-Tac-Toe game. |
| 04 | Arithmetic and Statistics | Covers basic arithmetic operations and statistical calculations in Python. |
| 05 | Python Libraries | Explores Math, NumPy, SciPy, Pandas, Matplotlib, and Seaborn. |
| 06 | Data Preprocessing | Handles missing values, categorical encoding, and data normalization. |
| 07 | Linear Regression | Builds a regression model using the Auto MPG dataset. |
| 08 | Logistic Regression | Applies classification using the Breast Cancer dataset. |
| 09 | Naive Bayes | Implements probabilistic classification using the Iris dataset. |
| 10 | Decision Tree and Random Forest | Explores tree-based classification using the Heart dataset. |
| 11 | K-Means Clustering | Groups data points using an unsupervised learning approach. |
| 12 | Hierarchical Clustering | Implements hierarchical clustering and compares its results with K-Means. |

## 🚀 Getting Started

Follow these steps to run the experiments on your local machine.

### 1. Clone the repository

```bash
git clone https://github.com/PranavMahajan02/AIML-LAB.git
```

### 2. Navigate to the project directory

```bash
cd AIML-LAB
```

### 3. Install the required libraries

```bash
pip install numpy pandas scipy scikit-learn matplotlib seaborn
```

### 4. Run an experiment

Choose the Python file you want to execute.

For example, to run Breadth-First Search:

```bash
python bfs.py
```

Similarly, you can execute other experiments:

```bash
python Astar.py
python tictactoe.py
python preprocessing.py
python linear_reg.py
python logistic_reg.py
python bayes.py
python tree_rf.py
python kmeans.py
python hierarchical.py
```
